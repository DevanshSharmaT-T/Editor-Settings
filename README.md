# Editor Settings

A collection of personal editor configs and customizations, shared publicly so anyone can use them, tweak them, or contribute their own.

This repo currently includes setups for:

- **LazyVim**
- **Sublime Text**
- **VS Code**
- **Zed**

## What's in here

Each folder contains the configuration files for that editor — themes, keybindings, extensions/plugins lists, and other settings I personally use day to day.

## Using these configs

Feel free to browse any folder and copy over what you like into your own editor setup. You're welcome to mess around with my configs as well as anything other contributors have added — nothing here is precious, so experiment freely.

## Contributing

This repo is open to public contributions. If you'd like to add your own setup:

1. Fork the repo (or clone it if you have access).
2. Create a new branch **named after yourself** (e.g. `johndoe`, `jane-smith`).
3. Add your configs in an appropriately named folder (e.g. `vscode/yourname` or a new editor folder if it's not listed yet).
4. Open a pull request from your branch.

See [GUIDE.md](./GUIDE.md) for more detailed step-by-step instructions.
